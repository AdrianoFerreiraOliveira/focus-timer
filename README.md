<h1>Focus Timer</h1>

<p>The Focus Timer is a simple web-based application that helps users manage their time using the Pomodoro technique. The app allows users to start, pause, and reset timers for focused work sessions, making it ideal for productivity.</p>

<h2>📂 Project Structure</h2>

<pre>
📂 focus-timer
 ├── 📁 .vscode               # VSCode settings
 ├── 📁 js                    # JavaScript files
 ├── favicon.ico              # Favicon for the webpage
 ├── index.html               # Main HTML file
 └── style.css                # CSS for styling the application
</pre>

<h2>🔨 Features</h2>

<ul>
  <li>Start, pause, and reset timers.</li>
  <li>Simple and intuitive interface.</li>
  <li>Adjustable time intervals for focus and break periods.</li>
</ul>

<h2>🛠️ How to Run the Project</h2>

<ol>
  <li>Clone the repository:
    <pre><code>git clone https://github.com/AdrianoFerreiraOliveira/focus-timer.git</code></pre>
  </li>
  <li>Navigate to the project directory:
    <pre><code>cd focus-timer</code></pre>
  </li>
  <li>Open the <code>index.html</code> file in your browser.</li>
</ol>

<h2>✔️ Technologies Used</h2>

<ul>
  <li><strong>HTML</strong>: Structure of the web application.</li>
  <li><strong>CSS</strong>: Styling for the user interface.</li>
  <li><strong>JavaScript</strong>: Functionality for the timer controls.</li>
</ul>
